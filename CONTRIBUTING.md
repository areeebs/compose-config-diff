# Contributing

Thanks for helping make Compose changes easier to review.

## Helpful contributions

- Report a confusing or incorrect path in the diff.
- Suggest a way to explain list changes more clearly.
- Add minimal before-and-after examples using fake values.
- Improve secret-key redaction without printing the values being checked.

## Guidelines

- Do not commit production Compose files or real credentials.
- Keep the tool read-only; it must not start or modify containers.
- Clearly document when a behavior is a limitation rather than a guarantee.
